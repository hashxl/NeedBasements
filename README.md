# NeedBasements

Mod for **Third Crisis** that adds a substance addiction system for Jenna. A vendor appears in Carceburg selling questionable products; each use increases addiction, triggers cravings more often, and changes Jenna's dialogue progression as she spirals.

## Features

- **Addiction system** — custom stat `Addicted to substances` (0–200) added to Jenna.
- **Vendor in Carceburg** — NPC appears when Jenna enters Carceburg; dialogues evolve based on purchase count.
- **Substances with distinct progression**:
  - **Cigar**
  - **Cigarette**
  - **Cannabis**
  - **Pills**
- **Dynamic cravings** — the higher the addiction, the more frequent Jenna's cravings become.
- **No mixing** — consuming a substance while another is still active is blocked with dialogue.
- **Progression stages** — each substance has multiple dialogue stages, from “just trying it” to total collapse.
- **Visual effect** — a pleasure effect is applied to Jenna's head while satisfaction is active.

## Combat modifiers (while the substance effect is active)

- **Cigar** — Lust Defense `+4`, Movement Speed `-2`
- **Cigarette** — Lust Power `+4`, Movement Speed `-2`
- **Pills** — Physical Power `+8`, Physical Defense `-4`
- **Cannabis** — Energy `+3`, Lust Defense `-4`
